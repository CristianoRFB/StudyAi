# RFB Method · Negotiation

## Decisões do projeto

- Prioridade: atender à avaliação AV_FINAL com software demonstrável e documentação verificável.
- Tecnologias: Python/Streamlit para apresentação acadêmica e Cloudflare Worker para demonstração web.
- Restrições: custo preferencial R$ 0, não armazenar conversas particulares e não expor credenciais.
- Concessão técnica: a busca Cloudflare utiliza correspondência lexical, diferente do TF-IDF Python; a diferença deve ser informada ao professor.
- Pendências para declaração de 90%: Gemini testado, rate limiting se habilitar chave pública, apresentação registrada e relatório com autoria.
